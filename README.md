# Jadeite Junction

Full-colour Python 3 neon pipe-dream arcade for [ElbowOS](https://x.com/ElbowOS).

Twist jade pipe tiles so copper source meets the rose drain. Lit junctions pulse gold. Complete a circuit to bank FLOW and refresh the board.

Click a tile to rotate. R resets. ESC quits.

## Play

```
pip install -r requirements.txt
python3 jadeite_junction.py --play
```

## Record a 9:16 reel

```
python3 jadeite_junction.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
